# Skills Disponíveis

Aqui estão as skills configuradas e disponíveis no seu ambiente atual (carregadas via os plugins do assistente):

## Desenvolvimento Web e Frontend
- **modern-web-guidance**: Melhores práticas modernas de desenvolvimento web (HTML/CSS, JS no cliente).
- **chrome-devtools**: Debugging e automação usando Chrome DevTools MCP.
- **debug-optimize-lcp**: Diagnóstico e otimização de Largest Contentful Paint (LCP) e Core Web Vitals.
- **memory-leak-debugging**: Diagnóstico de vazamentos de memória em aplicações JavaScript/Node.js.
- **chrome-extensions**: Construção e publicação de extensões do Chrome (Manifest V3).
- **a11y-debugging**: Debugging e auditoria de acessibilidade (a11y) baseados nas diretrizes do web.dev.

## Desenvolvimento Mobile e Flutter/Dart
- **flutter-* (Várias)**: Implementação de layouts responsivos, roteamento declarativo, internacionalização, serialização JSON, previews de widgets e boas práticas de arquitetura.
- **dart-* (Várias)**: Criação de apps CLI, cobertura de testes, geração de mocks, resolução de conflitos de pacotes, análise estática e correção de erros em tempo de execução.
- **android-cli**: Instalação e uso da ferramenta de linha de comando `android`.
- **xcode-project-setup**: Modificação segura de projetos Xcode (.pbxproj).

## Dados e Google Cloud Platform (GCP)
- **bigquery-* (Várias)**: Otimização de SQL, uso do BigFrames (pandas para BQ), Transfer Service, e ML embutido no BigQuery.
- **gcp-data-pipelines**: Ponto de entrada principal para construir, gerenciar e orquestrar pipelines de dados no GCP.
- **dbt-bigquery / dataform-bigquery**: Criação, modificação e otimização de pipelines dbt e Dataform.
- **gcp-spark / gcp-dataflow**: Pipelines de processamento Apache Spark e Apache Beam.
- **gcp-managed-airflow-***: Criação, migração e tuning de DAGs do Apache Airflow / Cloud Composer.
- **google-cloud-storage-basics / gcs-security-assessment**: Gestão, auditoria e segurança de buckets GCS.
- **bigtable-basics**: Provisionamento e queries no Bigtable.

## Firebase e Backend
- **firebase-basics**: Setup fundamental e workflows com Firebase CLI.
- **firebase-firestore**: Configuração, queries e regras de segurança para Firestore.
- **firebase-auth-basics**: Configuração de autenticação.
- **firebase-app-hosting-basics / firebase-hosting-basics**: Deploy de aplicações web e microsserviços.
- **firebase-data-connect**: Backends PostgreSQL com Firebase.
- **firebase-crashlytics / firebase-remote-config-basics**: Relatórios de erros e configuração remota.

## GenAI e Machine Learning
- **gemini-api-dev / gemini-interactions-api**: Desenvolvimento de aplicações com a API do Gemini.
- **gemini-live-api-dev**: Aplicações de streaming bidirecional em tempo real (áudio/vídeo/texto).
- **gemini-omni-flash-api**: Geração e edição de vídeo usando Gemini Omni Flash.
- **ml-best-practices**: Práticas recomendadas para clustering, classificação, regressão e análise de dados.

## Ciências e Bioinformática (Plugins de Ciência)
- Bancos de dados Genômicos e Variantes: **gnomad-database**, **clinvar-database**, **dbsnp-database**, **alphagenome-***
- Estruturas de Proteínas e Sequências: **pdb-database**, **alphafold-database-fetch-and-analyze**, **foldseek-structural-search**, **protein-sequence-similarity-search**
- Expressão e Vias: **gtex-database**, **reactome-database**, **string-database**
- Farmacologia e Ensaios Clínicos: **chembl-database**, **clinical-trials-database**, **openfda-database**, **opentargets-database**
- Pesquisa de Literatura: **literature-search-* (arxiv, biorxiv, openalex, europepmc)**, **pubmed-database**

## Assistente e Automação (Antigravity)
- **antigravity-guide**: Guia e referência para uso do próprio assistente (Antigravity CLI e extensões).
- **agy-customizations**: Guia para criar skills, plugins e ferramentas MCP personalizadas.
- **google-antigravity-sdk**: Desenvolvimento de agentes autônomos.
- **workflow-skill-creator**: Transformar um fluxo de trabalho do usuário em uma nova skill reutilizável.
- **migrate-workflows**: Migração de workflows legados para o formato atual.
