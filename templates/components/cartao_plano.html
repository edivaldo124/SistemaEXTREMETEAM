Estilo em .et-plano, .et-planos e .et-borda-brilho (componentes.css). #} {% from "components/ui.html" import estado_vazio with context %} {# `plano`: dict com nome, preco_total, preco_mes, meses, duracao_texto ('3 meses'), economia (número ou none), url_matricula, texto_botao; opcionais: unidade ('por mês' se ausente; 'por 7 dias' em plano curto), preco_mes_cheio e promocao_ate (promoção valendo: mostra o "de" riscado e o selo com a data final) `destaque=true`: cartão escuro, maior, com selo "Recomendado", botão primário dourado e a borda brilhante. {{ plano.nome }}

{%- if plano.preco_mes_cheio %} De {{ plano.preco_mes_cheio|moeda }} por {%- endif %} {{ plano.preco_mes|moeda }} {{ plano.unidade or 'por mês' }}

{%- for p in _ordem %} {{ cartao_plano(p, destaque=(p is sameas _ns.destaque)) }} {%- endfor %}
