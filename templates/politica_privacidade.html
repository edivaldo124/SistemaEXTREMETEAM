Política de Privacidade

Esta política explica como a Extreme Team trata os dados usados no sistema de gestão da academia.

  1. 1. Dados tratados
  2. 2. Integração com o Gmail
  3. 3. Finalidades
  4. 4. Compartilhamento
  5. 5. Segurança e retenção
  6. 6. Direitos e contato

1. Dados tratados

Podemos tratar nome, CPF, data de nascimento, dados de contato, informações de matrícula, presença, plano e pagamentos, além dos dados necessários para autenticação e segurança da conta.

2. Integração com o Gmail

Quando o administrador conecta uma conta Gmail, o sistema solicita somente a permissão necessária para enviar e-mails em nome dessa conta. O sistema não lê, lista ou altera mensagens da caixa de entrada.

O Google informa ao sistema o endereço da conta autorizada e um token de atualização. Esse token é armazenado cifrado no banco de dados, não é exibido na tela e não é incluído em logs. A conexão pode ser removida pelo administrador a qualquer momento.

3. Finalidades

Os dados são usados para administrar matrículas, planos, presença, pagamentos, comunicação com alunos, recuperação de acesso, segurança e cumprimento de obrigações legais.

4. Compartilhamento

Não vendemos dados pessoais. Os dados podem ser enviados a prestadores necessários ao funcionamento do serviço, como provedores de hospedagem, banco de dados, pagamentos e envio de e-mails, sempre conforme a finalidade da operação.

5. Segurança e retenção

Aplicamos controle de acesso, proteção de sessão, criptografia de credenciais e registro de eventos necessários à segurança. Mantemos os dados pelo período necessário às finalidades do serviço e às obrigações legais, excluindo-os quando não houver motivo legítimo para conservação.

6. Direitos e contato

Para solicitar acesso, correção, exclusão ou esclarecimentos sobre seus dados, entre em contato com a administração da academia pelo endereço informado no sistema.

Esta página pode ser atualizada quando houver mudança relevante no tratamento de dados.
